### マイスロ「中断データ」画面との対応（実機の画面で確認済み・2026-10-03）
ユーザーは、この画面を見ながら数値を入力する。画面の項目と入力項目の対応:

| マイスロの項目 | 入力項目 |
|---|---|
| 通常プレイ数（**CZ込みではない方**） | `game_count`（推定の分母。画面の「初当り確率1/256.0」＝通常プレイ数÷初当り回数で確認済み） |
| 総プレイ数 | `total_game_count` |
| 初当り回数 | `at_count`（CZ成功＋直撃AT。画面の例: 11回＝CZ成功7＋直撃4） |
| 悪人成敗チャンス全体（成功/**総回数**） | `cz_count` には**総回数**を入れる（例: 7/8 → 8）。直撃ATは含まない |
| 悪人成敗チャンス 柳生（成功/総回数） | `yagyu_count` には**総回数**を入れる（柳生が対戦相手に選ばれた回数） |

- 画面の「悪人成敗チャンス確率 ※直撃ATを含む」（例: 1/234.7）は、通常プレイ数÷（CZ総回数＋直撃AT）。**直撃ATを含む**。
- 入力欄の説明文に上の対応（「マイスロ中断データの『総回数』を入れる」）を表示する。
- 画面に項目が無いもの: 抜刀チャンス（`batto_log` は手でメモする）。

### 設定差の有無（マイスロ画面の項目別）
- **設定差あり（推定に使う）**: 初当り（AT）、悪人成敗チャンス、柳生選択率、抜刀チャンス（画面に無い）
- **設定差なし**（解析サイトで共通と明記）: 弱・強レア役の合算確率、勧善懲悪RUSH突入、真高確率関連、真BIG、鷹ブレイク
- **不明（入力欄を作らない）**: 共通ベル。実戦の観測値（設定1が1/325.9、設定6が1/147.6）を1サイトが載せているが、公式値ではなく、他のサイトの「小役は設定共通」とも食い違うので使わない。
- 弱チェリー・スイカ・チャンス目などの個別確率は、設定差の記載なし。

### 未確認の事項（推測で埋めない。コメントに残す）
- AT初当たりの分母: ユーザーの判断で**通常プレイ数（CZ込みでない方）**。ただし解析サイトの確率がどのゲーム数で数えた値かは未確認。要検証と明記。
- **CZ出現率（1/313.0〜1/250.6）が直撃ATを含むかどうか**が未確認。暫定: `cz_count`（直撃を含まない総回数）÷`game_count` で計算する。
  画面の例（8回/2816G=1/352、直撃込みなら1/234.7）では、どちらで数えるかで設定1と設定6くらい違って見える。
  解析サイトの定義が分かるまで、**2通りを並べて表示する**（§4）。
- 直撃ATは天井（AT間1500G／リセット後1000G）やモードCの周期到達でも起きるため、設定の高低とは関係なく出る。
  実機の例: 直撃4回でも、グラフは差枚ほぼ0で高設定とは言えない台だった（ユーザー報告）。
  直撃の多い台では AT初当たりが良く見えて設定が過大に出るので、画面に注意書きを出す（§4）。
- 柳生選択率の母数: CZ総回数（柳生を含む全対戦相手の回数の合計）、分子=柳生の総回数。
- 設定2〜5の機械割は chonborista の値（他サイト未確認）。

## 3. 入力項目
既存の `game_count`・`total_game_count`・打-WIN取り込み欄・ヒント欄は流用。追加フィールド:
- `at_count`: AT初当たり回数
- `cz_count`: CZ（悪人成敗チャンス）の総回数（直撃ATは含まない。マイスロ画面の「悪人成敗チャンス全体」の総回数）
- `direct_at_count`: 直撃ATの回数（任意）。マイスロ画面では「初当り回数 − 悪人成敗チャンスの成功数」で出せる（自動計算はしない。手入力）。
  空欄なら §4 の「直撃込み」の推定は出さない。
- `yagyu_count`: CZで対戦相手が柳生だった回数（`cz_count` 以下。超えたらバリデーションエラー）
- `batto_log`: 抜刀チャンスの成否を1件ずつ記録 `[{ id, win: boolean }]`
  （ボタン「抜刀チャンス当選」「抜刀チャンス外れ」。押すたび自動保存、×で削除。
  説明文に「メーターMAX時のみ。AT終了後の初回と5周期目は記録しない」と表示）
- 空欄=未計測は計算に使わない。0と区別する。

## 4. buildEstimate
既存機種と同じ呼び方で `estimateSettingLikelihoods(samples)` に渡す。samples:
- AT初当たり（k=`at_count`, n=`game_count`）
- CZ出現（**直撃を除く**: k=`cz_count`, n=`game_count`）← 主の推定（`likelihoods`）に使う
- 柳生選択（k=`yagyu_count`, n=`cz_count`。`cz_count` が0または空欄なら使わない）
- 抜刀チャンス（k=win件数, n=総件数）
- 示唆は `hintMinSetting` / `excludedSettings` に反映（尤度には混ぜない）

**CZの2通り表示**: `direct_at_count` が入力されているときだけ、CZ出現を
（k=`cz_count`+`direct_at_count`, n=`game_count`）＝「直撃込み」に差し替えた推定をもう1つ作り、
戻り値に `alternativeEstimates: [{ label: "CZ直撃込みで計算", likelihoods }]` として返す
（`likelihoods` / `samples` など契約上の項目は主の推定のまま。`summarizeEstimateHeadline` は主の推定だけを見る）。
推定パネルは、主の推定のバーの下に `alternativeEstimates` があれば同じ形のバーを並べ、
「どちらの定義が正しいか未確認（要検証）」と表示する。この表示の仕組みは他機種が使えるよう汎用にする（吉宗専用の描画にしない）。

**注意書き**（`direct_at_count` が1以上のとき）: 「直撃ATは天井やモードC周期でも起きます。設定が良い台とは限りません。AT初当たりが実際より良く出ている可能性があります」。
直撃を除いたAT回数での推定は、`at_count` − `direct_at_count` を k にしたAT初当たりを `alternativeEstimates` に**含めない**（解析サイトのAT初当たりは直撃込みの値と読めるため、AT初当たりは常に `at_count` で計算する）。
